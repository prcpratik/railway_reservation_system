PHOTO REQUIREMENTS
  Format : JPG (recommended) or PNG
  Shape  : square (1:1) - same width and height, e.g. 400 x 400 px
  Size   : around 400x400 px is ideal; keep each file under ~200 KB
  Note   : the photo is shown inside a circle, so keep the face centred.

The filenames must match exactly (all lowercase). If a photo is missing,
the page automatically shows the first letter of the name instead.

To change a filename, edit the "img" value in src/pages/About.jsx.
